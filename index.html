📖 คู่มือการใช้งาน

เริ่ม/หยุดทำงาน

  • กด "▶ เริ่มทำงาน" เมื่อเริ่มเดินเครื่อง PM-500A/B — ตัวจับเวลาจะเริ่มนับทันที
  • กด "⏹ หยุดทำงาน" เมื่อหยุดเดินเครื่อง ระบบจะบันทึกเป็น 1 Session ลงประวัติอัตโนมัติ

ชั่วโมงสะสม / รีเซ็ต PM

  • "ชั่วโมงสะสม" นับรวมทุก Session ตั้งแต่การรีเซ็ตครั้งล่าสุด
  • กด "รีเซ็ต" เมื่อครบรอบ PM — ต้องกรอกค่า PD-2500.PV, จำนวนรอบเปิด B/V bypass PE-501/LCV-2502 และหมายเหตุ
  • ถ้าลืมกดรีเซ็ตตอนนั้นจริง สามารถเลือก "วันที่/เวลาที่จะรีเซ็ต" ย้อนหลังในฟอร์มได้ ระบบจะคำนวณชั่วโมงสะสม ณ เวลานั้นให้ถูกต้อง
  • ตั้ง "เป้าหมาย PM ต่อรอบ (วัน)" แยกได้ต่อเครื่องในแท็บ "รายงานสรุป"

แก้ไขประวัติ Session ย้อนหลัง

  • ในแท็บ "ประวัติ Session" กด "แก้ไข" ที่แถวใดก็ได้เพื่อแก้เวลาเริ่ม/เวลาหยุดย้อนหลัง
  • ถ้า Session ยังทำงานอยู่ (ลืมกดหยุด) ใส่ "เวลาหยุด" ย้อนหลังในฟอร์มนี้เพื่อปิด Session ได้เลย โดยไม่ต้องกดหยุดสด

เปลี่ยน Filter

  • กด "🧰 บันทึกเปลี่ยน Filter" ที่การ์ดของเครื่องนั้นทุกครั้งที่เปลี่ยน Filter จริง — ระบุค่าใช้จ่ายและหมายเหตุได้
  • เมื่อชั่วโมงทำงานสะสมนับจากครั้งที่เปลี่ยนล่าสุด ถึงเป้าหมายที่ตั้งไว้ (แท็บ Filter) การ์ดจะขึ้นป้ายเตือน "ถึงกำหนดเปลี่ยน Filter แล้ว"
  • เครื่องที่มีชั่วโมงสะสม (นับจากรีเซ็ต PM ล่าสุด) มากกว่าอีกเครื่อง จะขึ้นป้าย "🔜 คาดว่าจะถึงคิวเปลี่ยน Filter รอบหน้า" ให้ล่วงหน้า
  • ตั้งเป้าหมายชั่วโมงแยกได้ต่อเครื่องในแท็บ "Filter"

รายงาน

  • แท็บ "รายงานสรุป" ดูสรุปรายวัน/รายเดือนแยกทีละเครื่อง พร้อมกราฟชั่วโมงใช้งานต่อรอบ

⚙️ ตั้งค่า

  • ส่งออกข้อมูล (.json) — สำรองข้อมูลทั้งหมดเก็บไว้ หรือย้ายไปเปิดเครื่องอื่น
  • นำเข้าข้อมูล (.json) — กู้คืนจากไฟล์สำรอง (จะแทนที่ข้อมูลปัจจุบันทั้งหมด ต้องยืนยันก่อนเสมอ)
  • รายงานสรุป (พิมพ์ได้) — ไฟล์ HTML สรุปข้อมูลทั้งหมด เปิดดู/พิมพ์ได้โดยไม่ต้องใช้แอป
  • สำเนาแอปแบบ Standalone — ไฟล์ HTML ที่รันแอปได้ในตัวเอง พร้อมฝังข้อมูลปัจจุบันไว้ เผื่อเก็บสำรองแบบเปิดใช้งานต่อได้ทันที
